# Installation

## From PyPI

```bash
pip install dbt-kylin
```

## From a local checkout (editable)

```bash
python -m pip install -e dbt-kylin
```

## From a built artifact

```bash
python -m pip install dist/dbt_kylin-<version>-py3-none-any.whl
```

## Verify

```bash
dbt --version
```

Then configure a profile (see README).
